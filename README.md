# 🇪🇹 Task 1: EthioFill – UX Redesign for Traditional Food Delivery

## 📌 Project Overview
**EthioFill** is a digital solution designed to modernize the traditional Ethiopian food delivery market. The goal of this redesign is to improve user trust and conversion rates for local catering services.

---

## 🎯 The Challenge
Local food businesses in Ethiopia often struggle with:
* **Complex Navigation:** Users find it hard to browse large traditional menus.
* **Lack of Trust:** No clear indication of "Freshness" or "Teff Quality."
* **Weak CTAs:** Buttons like "Order Now" are often hidden or non-existent on mobile.

## 💡 The Solution (UX Strategy)
1. **Appetite-First Visuals:** Using high-fidelity imagery of authentic cuisine to trigger immediate user interest.
2. **Simplified Booking Flow:** A 3-step checkout process (Select -> Schedule -> Confirm).
3. **Habesha Branding:** A color palette inspired by Ethiopian heritage (Teff Brown, Berbere Red, and Gold).
